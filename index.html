Pistas de treino

Experimente as duas missões no navegador. As arenas são referências para treinamento.

Anexo I

Missão Controlada

Dirija com as setas, use Shift para maior velocidade e Espaço para parar. Envie respostas pelos botões na tela. Treine visitar três estações e voltar à largada.

Para usar os controles físicos, abra a pista no Chrome ou Edge e siga as instruções de conexão do receptor micro:bit por USB.

Anexo II

Missão Autônoma

Escolha Quatro sensores para simular o seguidor de linha ou Volta guiada para conhecer o traçado. Inicie a volta e acompanhe o cronômetro.

Use o guia 3D de montagem para consultar o chassi e as ligações do carrinho.
